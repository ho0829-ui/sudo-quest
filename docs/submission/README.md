# InfraCoach — AI 코어 프로젝트 2회차 제출 안내

**제출 주제:** 공식 문서를 근거로 인프라 장애 대응을 돕는 RAG 코치. 브라우저의 가상 장애 실습 **SUDO QUEST**와 연결했습니다.

![가상 장애 실습과 결과 리포트 시연](../assets/demo/main.gif)

핵심 특화 기능은 **실습 기록 기반 코치**입니다. 사용자가 본 티켓·명령·출력만 서버에 보내며, 정답과 전체 게임 상태는 보내지 않습니다. 답변의 문서 인용 번호를 검증하고, 근거가 부족하면 답을 보류합니다. [코치 시연 GIF](../assets/demo/coach.gif)

## 결과를 읽을 때

[검증 결과](검증결과.md)와 [기존 RAG 전후 비교](RAG_전후비교.md)는 **2026-10-21 당시 환경과 데이터**의 기록입니다. 이후 시나리오·카탈로그·테스트가 확장되었으므로 현재 전체 서비스의 숫자로 합산하지 않습니다. 보강 평가 24문항의 방법·결과·한계는 [RAG 평가 v2](../infra-coach/22_RAG_근거_보강.md)에 따로 기록했습니다. 두 평가는 표본과 채점 방식에 한계가 있습니다.

**현재 코드 재검사(2026-10-23, Mac):** 프론트 957개·백엔드 87개 테스트, 타입 검사·빌드 통과. 실제 모델 품질과 외부 접속은 이번 재검사 범위에 포함하지 않았습니다.
