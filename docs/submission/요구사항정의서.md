# 요구사항 정의서 — InfraCoach

AI 코어 프로젝트 2회차 · RAG 기반 도메인 지식 서비스 · 작성일 2026-10-21

상태 표기: **구현·검증** = 구현했고 이번 프로젝트에서 실제 실행으로 확인함 · **구현·부분 검증** = 구현했지만 일부 조건만 확인함 · **미구현** = 범위에서 제외함. 검증 근거는 `검증결과.md`의 시험 번호(T-xx)로 연결한다.

## 1. 서비스 개요

InfraCoach는 인프라 장애·오류를 다루는 지식 서비스다. 사용자는 공식 문서를 근거로 질문하고, 브라우저 안의 가상 장애 실습에서 막혔을 때 **자신이 직접 관찰한 기록과 공식 문서만으로** 다음 점검을 안내받는다.

- 대상: Linux·네트워크 기초를 배운 인프라 입문자(공기업 전산직·인프라·클라우드 지망)
- 기반: 기존 React/TypeScript 가상 장애 대응 게임(13개 실습, 가상 상태 엔진). 여기에 Python(FastAPI·LangGraph·Chroma) RAG 서버를 추가했다.
- 역할 분리: 실습의 복구 판정은 **게임 엔진**이 하고, RAG는 **설명과 코칭**만 한다. 코치는 실습의 정답·풀이·숨겨진 상태를 받지 않는다.

- 모든 문서는 출처 정의 파일(`backend/catalog/sources.json`)과 문서 메타데이터(`documents.json`)에 출판자, 라이선스, 이용 조건 URL을 기록했다. 청크 메타데이터와 화면의 근거 카드에도 출판자와 라이선스를 표시한다.
- 저장소에는 원문 발췌(항목 `source_excerpt`, 절 카탈로그 요약)가 들어 있다. 그래서 저작자·라이선스·변경 사항을 `THIRD_PARTY_NOTICES.md`에 고지했다. 원문 전체 캐시(`backend/data/`)는 Git에서 제외한다.
- 확인 범위의 한계:
  - Linux man-pages 라이선스는 소스 파일의 SPDX 표기로 확인했지만, man-pages-6.19 태그와 같은 파일인지는 확인하지 못했다.
  - 이 확인 과정에서 git.kernel.org에 4회 수동 요청을 보냈다. 이후 확인해 보니 이 사이트의 robots.txt는 모든 자동 요청을 금지하고 있다. 수집기에는 이 호스트를 넣지 않았다(검증결과 T20).

### 2.3 근거 없이 답하면 틀리거나 위험해지는 질문

| 질문 | 근거 없이 답할 때의 위험 | 근거 |
|---|---|---|
| ALB 타깃이 모두 unhealthy이면 항상 503인가? | "그렇다"고 답하면 잘못된 원인 판단으로 이어진다. 공식 문서는 fail-open을 설명한다. | ALB 헬스체크 문서 |
| curl 404 응답은 항상 종료 코드 22인가? | 스크립트의 실패 판정을 잘못 설계한다(--fail일 때만 22). | curl 매뉴얼 Exit codes |
| ALB 408을 TCP keep-alive로 막을 수 있나? | 효과 없는 설정 변경에 시간을 쓴다. | ALB 문제 해결 HTTP 408 |
| ALB 503 때 AWS 지원 플랜 응답 시간은? | 색인 범위 밖이다. 단정하면 확인되지 않은 정책을 사실처럼 전달한다. | (보류해야 하는 질문) |

RAG 사용 전후의 실제 답변 비교는 `RAG_전후비교.md`에 있다(9문항, T14).

### 2.4 위험 도메인 여부

건강·금융처럼 조언이 직접 위험한 도메인에는 해당하지 않는다. 다만 실제 서버에 잘못 조치하면 장애를 키울 수 있으므로 다음을 안내한다.

- 지식 화면: "실제 운영 환경의 진단·복구 판단을 대신하지 않으니, 실서버 조치 전에는 원문 문서와 담당자 절차를 확인하세요."
- 실습 코치: "복구 판정은 게임이 합니다."
- 가상 실습: "가상 환경 · 실제 시스템에 영향 없음."

## 5. 범위 밖과 알려진 한계

- (해결됨) 게임 ALB 실습이 "모든 타깃 unhealthy → 503"을 전제로 해 공식 문서와 달랐다. "HealthyHostCount=0 알람, 사이트는 정상(fail-open)"으로 고쳤다(T23).
- 실습의 정답 데이터는 브라우저 코드에 포함되어 있다(원인 보기 순서도 고정). 코치로는 전달되지 않지만 시험 수준의 정답 보호는 아니다.
- 한국어 제목·증상·요약 100건은 LLM 보조로 작성했고 사람 검수 전이다(`annotation_origin`에 표시).
- 공식 셀프 체크리스트(3일차 오후 제공)와 동료 상호 점검은 아직 하지 않았다.
- 배포는 하지 않았다. 로컬 시연 기준이다(정적 GitHub Pages에서는 Python 서버가 동작하지 않는다).
