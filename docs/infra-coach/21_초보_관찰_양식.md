# 21. 초보 사용자 관찰 양식 (2026-10-23, Mac, Claude)

20번 정리 A6. 인프라를 잘 모르는 사람 2~3명이 **튜토리얼 → 1번 → 6번 실습**을 하는 모습을 보고, 어디서 막히는지 기록한다.
사람 섭외와 진행은 Choi, 결과 정리와 수정 목록은 Claude가 맡는다.

## 1. 준비

- 화면: 노트북(1280×720 정도) 1명 이상, 휴대폰 1명 이상이면 좋다.
- 주소: 같은 빌드에서 진행하고 커밋 해시를 적어 둔다. 브라우저는 시크릿 창이 좋다(튜토리얼 "봤음" 표시·기록이 남지 않은 처음 상태).
- AI 코치를 쓸지 정한다: 서버를 켜면 코치까지 관찰, 끄면 게임만 관찰(어느 쪽인지 기록).
- 동의: "화면과 말한 내용을 메모하고, 이름 없이 개선에만 쓴다. 언제든 그만둬도 된다." 녹화는 따로 허락받을 때만.

## 2. 진행 규칙 (관찰자)

- 처음 한마디만 한다: "이 게임으로 서버 장애를 고쳐 보는 연습을 해요. 생각나는 걸 소리 내어 말해 주세요. 막혀도 제가 도와드리지 않을 거예요 — 막히는 곳을 찾는 게 오늘 목적이라서요."
- 질문을 받으면 답하지 않고 "어떻게 하면 될 것 같아요?"로 되묻는다. 5분 넘게 완전히 멈추면 그때만 "힌트 버튼이나 AI 코치를 써도 돼요"라고 말한다(개입했다고 기록).
- 시간은 화면별로 잰다. 점수는 보지 않는다(학습 점수라 비교 대상이 아님).

## 3. 과제

| 순서 | 과제 | 끝난 것으로 보는 때 |
|---|---|---|
| 1 | 홈에서 스스로 튜토리얼을 찾아 시작한다(버튼 위치를 알려 주지 않음) | 튜토리얼 브리핑 화면 |
| 2 | 튜토리얼을 끝까지 | 리포트의 "튜토리얼 끝내기" 또는 "1번 실습 시작하기" |
| 3 | 1번 실습 "웹사이트가 갑자기 안 열려요" | 리포트 화면 |
| 4 | 6번 실습 "결제 API 호출이 전부 실패해요"(네트워크·용어 풀이 확인) | 리포트 화면 또는 20분 경과 |
| 5 | 끝난 뒤 질문 3개(4절) | |

## 4. 끝난 뒤 질문

1. 가장 헷갈렸던 순간은 언제였나요? 그때 무엇을 하려고 했나요?
2. 튜토리얼 말풍선 중 쓸모없거나 너무 길었던 게 있었나요?
3. 힌트 아래 "용어 풀이"를 열어 봤나요? 도움이 됐나요, 아니면 정답처럼 느껴졌나요?
