## 발견·해결한 문제

- Windows 기본 cp949에서 한글 requirements 주석 읽기 실패: UTF-8 인코딩 선언과 `-X utf8` 실행으로 해결.
- sandbox DNS·로컬 소켓 제한: 승인된 외부 실행으로 의존성 설치, 테스트, 두 서버, GMS 호출 검증.
- Windows Chroma 임시 저장소 정리 시 파일 잠금: FastAPI lifespan 종료에서 `client.close()` 수행 후 테스트 통과.
- npm 설치 감사 결과 5건(중간 1/높음 2/치명 2)이 표시됐다. 이번 단계에서 기존 lockfile을 임의 업그레이드하지 않았다. 세부 영향 분석·업데이트는 후속 작업.
