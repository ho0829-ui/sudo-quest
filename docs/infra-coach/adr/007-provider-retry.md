# 007. 공급자 일시 장애만 1회 재시도

- **상황:** 08번 평가 중 GMS가 502를 한 번 냈고, 그때는 재시도가 0회라 사용자가 오류를 그대로 봤다. 반대로 키 오류(401)나 형식 오류는 몇 번을 다시 해도 같다.
- **결정:** 생성·임베딩 요청이 5xx·시간 초과·연결 끊김이면 1초 쉬고 1회만 다시 보낸다(`providers.with_retry`). 4xx·형식 오류·미완성 응답은 바로 실패. OpenAI SDK의 자체 재시도는 끈다(`max_retries=0`) — 재시도 규칙을 한곳에서 보이게 하려고. 공식 문서 수집(429 포함)은 사이트 예절상 자동 재시도하지 않는다.
- **버린 대안:** (1) 지수 백오프 여러 번 — 작업 하나가 수십 초 더 늘어 사용자는 결국 기다리다 떠난다. (2) 재시도 없음 — 일시 장애가 그대로 실패가 된다.
- **결과:** 일시 장애 한 번은 사용자에게 보이지 않는다. 대가: 최악의 경우 공급자 호출 하나가 시간 제한(`API_TIMEOUT_SECONDS`, 기본 30초) × 2 + 1초까지 늘어난다.
- **근거:** `backend/app/providers.py`, `test_resilience.RetryTests`, 22번 문서 1절.
