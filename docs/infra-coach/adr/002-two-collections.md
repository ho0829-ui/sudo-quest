# 002. Chroma 컬렉션 2개(항목 요약 / 원문 청크)

- **상황:** 학습 항목(131개)은 "무엇에 대한 것인가"(제목·증상·요약), 원문 청크(약 300개)는 "공식 문서가 정확히 뭐라고 하나"다. 성격이 다른 두 가지를 한 컬렉션에 섞으면, 짧은 요약이 긴 원문 청크와 점수를 다투고 항목 고르기와 근거 찾기를 구분하기 어렵다.
- **결정:** `knowledge_items`(항목 요약 = 메타데이터, 항목 고르기용)와 `reference_chunks`(원문 절 청크, `item_id`·`doc_id`·`source_url`)로 나눈다. 지식 질문은 고른 항목·선택 문서로 청크를 거르고, 코치는 항목을 모르면 `knowledge_items`에서 3개를 자동으로 고른 뒤 그 항목들의 청크만 검색한다.
- **버린 대안:** (1) 한 컬렉션 + `type` 메타데이터 — 가능하지만 검색마다 필터가 늘고, 항목 고르기 점수가 청크 수에 끌려간다. (2) 청크만 두고 항목은 키워드로 — 증상 문장(한국어)과 원문(영어) 사이의 연결을 놓친다.
- **결과:** 근거 1번은 항상 항목 요약, 2번부터 원문 청크라 인용 구조가 일정하다. 평가 v2에서 항목 자동 선택 Hit@3 18/18, 항목 범위 검색 Hit@4 18/18(22번 문서 3절). 대가: 같은 문서를 여러 항목이 공유하면 청크가 항목마다 따로 들어가 중복 저장된다(원문 수집은 URL 캐시로 한 번).
