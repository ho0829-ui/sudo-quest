# 작은 CLI 로딩과 퀘스트 담당자 연출

2026-10-22 · Mac · feature/sudo-quest

## 요청과 재개 기준

사용자 요청은 작은 CLI 모양 로딩, 픽셀 초상의 수염 있는 인물을 캠퍼스 그림체에 맞춘 담당자, 전신에서 상반신으로 줌인한 뒤 상황 설명·퀘스트 수락·CLI로 이어지는 흐름이다.

- 참고 영상은 제공된 Pinterest MP4를 브라우저에서 직접 열어 파란 점들이 모이고 흩어지는 실루엣을 확인했다. 영상 자체를 제품에 복사하지 않았다.
- 처음 `/Users/jaeho/image.png`·`0.png`는 없었다. 이후 사용자가 다시 첨부한 `/Users/jaeho/Downloads/0.png`의 아래 줄 안경·수염 모델을 참고했다. 원본을 제품에 넣지 않고 SVG로 새로 그렸다.
- 최신 Claude 인수인계(HEAD `0a57963`)에서 게시판 2단계, 시나리오 22개, 번들 분할 완료를 확인했다. 옛 대화의 게시판 미구현 상태를 덮어쓰지 않았다.
- 재개 시 이미 Web 시나리오 2개와 공통 상태 변경이 미커밋 상태였다. 이 작업은 해당 파일을 수정·스테이징하지 않았다. 현재 작업 트리는 24개 시나리오이며 아래 전체 검사도 그 작업 트리 기준이다.

## 구현

### CLI 로딩

- `components/TerminalLoader.tsx` + `terminal-loader.css`: 58×42px, compact 36×26px. 도트 창 테두리·프롬프트·커서. 사이트의 청록·보라 사용, 점이 흩어졌다가 다시 모인다.
- 상태 텍스트를 함께 제공하고 SVG는 보조기기에서 제외한다. 모션 일시정지와 시스템 reduced-motion에서 정지한다.
- App의 게시판/실습 lazy fallback, 저장 실습 복원, health 확인, 게시판 목록/상세/댓글, 코치 답변 대기, 지식 답변·조건 탐색 대기에 적용.
- `index.html`의 첫 JavaScript 로드 전에도 작은 도트 CLI 아이콘. React 마운트 후 교체되고 JavaScript가 꺼진 경우 별도 안내.
- 로딩을 보여 주기 위한 인위적인 네트워크 지연은 추가하지 않았다.

### 담당자와 퀘스트

- `quest/QuestOfficer.tsx`: 안경·수염·태블릿·작업 재킷의 선임 운영자 **도윤**. 캠퍼스의 색면/3/4 인물 표현을 이어받은 자체 SVG.
- `quest/QuestBriefing.tsx` + `quest.css`: 서버 랙 배경, 레터박스, 1.6초 카메라 줌, 상반신 구도, 대화 2단계. 긴 신고만 스크롤하며 하단 버튼은 보존.
- `quest/dialogue.ts`: 공개 `title`, `ticket`만 받는다. 신고 전체를 보존하며 원인·학습 목표·정답 명령을 가져오지 않는다. 대사는 로컬 텍스트이고 LLM 호출이 없다.
- 새 실습의 `조사 시작` → 담당자 등장 → 증상 설명 → `상황 확인했어요` → 도움 요청 → `퀘스트 수락 · 조사 시작` → 기존 PlayScreen.
- 세션 생성·타이머는 수락할 때 시작한다. 취소·Esc는 브리핑으로 돌아가며 포커스/본문 스크롤을 복원한다. Tab/Shift+Tab을 모달 안에서 순환시킨다.
- 연출 건너뛰기는 설명을 즉시 보여 주며 자동으로 수락하지 않는다. 모션을 끄거나 reduced-motion이면 즉시 설명.
- 기존 `조사 이어서 하기`는 대화를 반복하지 않고 바로 CLI로 연결. 리포트의 다시 도전 동작은 기존대로다.
- 담당자 그림·대화는 React.lazy로 별도 청크(8.64kB). Claude의 엔진/실습 코드 분할을 유지했다.

## 실제 검증

- `npm run typecheck`: 통과.
- `npm test`: **762개/31파일 통과**. 현재 미커밋 Web 확장 포함. 이번 UI 검사 5개는 `tests/quest-presentation.test.tsx`: 공개 신고 보존, 비공개 필드 미노출, 수락 전 시작하지 않음, 모션 꺼짐, HTML 이스케이프/로더 접근성.
- `npm run build`: 통과, 500kB 경고 없음. index 340.39kB, vendor 221.70kB, execute 107.39kB, PlayScreen 20.22kB, CommunityScreen 18.19kB, QuestBriefing 8.64kB. Web 확장 때문에 기존 316.9kB와 직접 UI 증가량 비교는 불가.
- 전체 `git diff --check`: 기존 미커밋 `src/engine/state/network.ts:171`의 EOF 빈 줄 1건 지적. 이 파일은 이 작업에서 수정하지 않았다. 이번 UI 스테이징 `git diff --cached --check`는 통과했고 `bbed91f`에 저장했다. 문서/증빙은 별도 docs 커밋.
- 브라우저 127.0.0.1:5173: 로딩 아이콘, 줌인, 두 단계 대화, 수락 후 CLI, `pwd` 출력, 뒤로가기→이어하기(명령 1개 유지), Esc 취소와 포커스 복원, Tab/Shift+Tab 순환, 연출 건너뛰기, 모션 끄기 즉시 대화 확인.
- 375×812: document 가로폭/스크롤폭 375/375, dialog 353/353. 812×375: 가로폭/스크롤폭 812/812, 수락 영역 아래 354px로 화면 안에 유지. 임시 viewport는 원복.
- 최종 브라우저 콘솔 error 0. 시험 탭 닫음. 기존 사용자 탭·학습 기록은 삭제하지 않았고 정답 제출·유료 질문은 하지 않았다.
- 증빙: `evidence/quest/{desktop,mobile,intro-loader}.png`.
- 백엔드 변경·재검증, 실제 RAG/색인, OS 접근성 설정 자체 변경 검증은 이번 UI 단계에서 하지 않았다. 시스템 reduced-motion은 코드/CSS 경로를 구현했고 브라우저에서는 앱의 모션 끄기로 검사했다.

## 남은 작업과 실행 상태

- 사용자 피드백: 담당자 얼굴/안경/수염·이름·줌인 속도·대사 길이. 아직 피드백 전이다. 음성/입 모양 동기화는 요청되지 않았고 구현하지 않았다.
- 이미 존재하던 Web 확장의 nginx upstream/TLS 체인 시나리오·엔진·탐색 테스트는 다음 도우미가 검토하고 별도 문서/커밋을 완성해야 한다. 전체 테스트 통과와 구현 완료 승인은 구분할 것.
- 서버 보존: Vite 5173(PID 87647), FastAPI 8000(PID 74575). 포트/PID는 재개 시 확인할 것.
- `.env` 값 읽기/덮어쓰기 없음, 새 런타임 의존성 없음, push/merge 없음.
- Claude 시작 프롬프트: `16_Claude_이어가기_프롬프트.md`.
